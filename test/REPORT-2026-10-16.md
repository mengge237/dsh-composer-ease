## 三、抓出的两个真缺陷（已修）

1. **Lexical 不认 `sel.modify(...)`**。捕获阶段做的选区操作在真 composer 上静默失效：配对后的光标跑到闭符之后、
   跳闭合失效、删空对只删一侧、环绕选区不还原、Tab 接受变成「insert 而不是 replace」（`ininputValue`）。
   修法：把 composer 文本摊平成字符偏移，用 `createTreeWalker` + 显式 `Range` 定位（`flatText`/`caretOffset`/`setSelectionRange`），
   删除路径也从 `sel.modify` 换过来。**离线测不出**——假 DOM 里 `sel.modify` 本来就不存在，文本路径（TEXTAREA）是另一条实现。
2. **捕获阶段早于宿主处理**，插入后立刻改选区会被 Lexical 随后的渲染覆盖。修法：contenteditable 这条路的选区调整
   用 `soon()`（`setTimeout 0`）推一拍。
   附带修掉一个文档漂移：「环绕选区后选区保持选中」原来只在 README 里成立（实现把 caret 停在闭符之后）。
